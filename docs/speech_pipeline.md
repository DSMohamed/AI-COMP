# 🎙️ Speech & Voice Pipeline

The speech pipeline provides real-time, low-latency, fully offline speech perception and neural audio synthesis for Windows.

## 1. Voice Activity Detection (`gaming_ai.speech.vad`)

The `VoiceActivityDetector` performs frame-by-frame RMS energy analysis with dynamic ambient noise floor tracking:

$$\text{RMS} = \sqrt{\frac{1}{N} \sum_{i=1}^{N} x_i^2}$$

### Dynamic Noise Floor Adaptation
During silence periods, the baseline noise floor $\text{NF}$ smoothly adapts:
$$\text{NF}_{t} = 0.95 \times \text{NF}_{t-1} + 0.05 \times \text{RMS}$$

The effective threshold for triggering speech onset is dynamically gated at:
$$\text{Threshold}_{\text{eff}} = \max(\text{ConfigThreshold},\ 2.5 \times \text{NF})$$

### Speech State Machine
* **Speech Onset**: Energy exceeds $\text{Threshold}_{\text{eff}} \implies$ fires `speech_started` and records timestamp.
* **Speech Ongoing**: Speech frames continue to update `last_speech_time`.
* **Speech Endpoint**: Silence duration $\ge \text{vad\_silence\_duration}$ (default: `0.8s`) and total speech duration $\ge 0.3\text{s} \implies$ signals utterance completion.

## 2. Speech-to-Text (`gaming_ai.speech.stt`)

Powered by **faster-whisper** using CTranslate2:
* **Quantization**: `int8` (reduces memory consumption by ~65% with zero perceivable loss in gaming transcript accuracy).
* **Sample Rate**: 16,000 Hz, mono float32.
* **Inference Latency**: 150 – 250 ms for typical 3–5 word gaming utterances.

---

## 3. Interruptible Audio Playback (`gaming_ai.speech.audio_player`)

Natural conversation requires that the companion stops talking the instant the user speaks.

### Mechanism:
1. `InterruptibleAudioPlayer` runs a dedicated playback worker queue.
2. When the user starts speaking, `MicrophoneStream` triggers the `on_speech_started` callback.
3. `agent._on_speech_started()` calls `tts.interrupt()`.
4. `InterruptibleAudioPlayer.interrupt()` sets an internal cancellation flag and drains all pending sentences from the queue immediately ($< 20\text{ms}$).

---

## 4. Text-to-Speech Streaming (`gaming_ai.speech.tts`)

Rather than waiting for the entire LLM response to generate (which would introduce a 1.5–3.0s latency barrier), `TextToSpeechEngine` uses **Sentence-Level Streaming**:

1. Tokens stream in from Ollama (`llama3.2:3b`).
2. A regex buffer splits incoming tokens on sentence boundaries (`[.!?\n]+`).
3. Each finished sentence is immediately sent to the audio player while subsequent sentences are still being generated by the LLM.
4. Perceived latency to first audio output is **< 150 ms**!

## 5. Neural Human Voices & Free Tool Integrations

To make the companion sound like a real human friend rather than a robotic synthesizer, the pipeline supports multiple high-definition neural voice backends:

### A. Edge-TTS (Microsoft Neural — 100% Free Online, Zero Hardware Usage)
* **Default Engine**: Uses Microsoft's cloud neural streaming voices for crystal-clear quality with human breathing and pitch inflections.
* **Top Voices**:
  * `en-US-ChristopherNeural` (Energetic male co-op partner)
  * `en-US-GuyNeural` (Laid-back casual streamer buddy)
  * `en-US-JennyNeural` (Friendly, enthusiastic teammate)
  * `en-GB-RyanNeural` (Sarcastic dry-humor British coach)
* **Configuration**:
  ```yaml
  tts:
    engine: "edge-tts"
    voice: "en-US-ChristopherNeural"
  ```

### B. AllTalk TTS / Coqui XTTS v2 (Local Neural Voice Cloning)
* **Web UI & Local API**: [AllTalk TTS](https://github.com/erew123/alltalk_tts) runs locally on port 7851.
* **3-Second Voice Cloning**: Clones any streamer or game character voice from a 3-second `.wav` clip.
* **Configuration**:
  ```yaml
  tts:
    engine: "alltalk"
    voice: "my_custom_voice.wav"
  ```

### C. Suno Bark (Local Transformer Emotion & Non-Speech Sounds)
* Generates non-speech emotional cues like `[laughs]`, `[sighs]`, and `[gasps]` for ultra-realistic gaming reactions.

### D. Kokoro-82M (Ultra-Lightweight 82M Local CPU Model)
* State-of-the-art 82M open-source model delivering studio-quality cadence with $<100\text{ms}$ latency on CPU.
